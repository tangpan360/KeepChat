# Product Overview

## 产品定位
KeepChat 的近期形态是一个可上架 Chrome Web Store 的侧边栏 AI 助手，面向普通用户，核心价值是随时可用的聊天、图文问答和网页辅助能力。

长期来看，KeepChat 不只是一个浏览器插件，而是一套从浏览器入口逐步演进到论文阅读、问答、写作与编辑平台的产品体系。

## 近期目标
- 做一个安装后即可使用的 AI 侧边栏。
- 优先验证聊天、图片问答、翻译、总结等高频场景。
- 在不明显增加权限和复杂度的前提下，逐步增加网页引用能力。

## 长期目标
- 支持当前网页问答与多网页问答。
- 支持 PDF 上传、解析、阅读与问答。
- 支持多篇论文的知识库问答与检索增强。
- 最终演进为独立网页平台，提供论文阅读、翻译、标注、写作、改写和 diff 审核能力。

## 产品演进路线
### 阶段 1：通用聊天助手
- 文本聊天
- 图片上传与问答
- 多轮对话
- 历史会话
- 快捷动作，如翻译、总结、解释、改写

### 阶段 2：网页增强问答
- 选中文本引用
- 右键发送到侧边栏
- 当前网页问答
- 多段引用
- 网页图片拖拽问答

### 阶段 3：资料与文档能力
- 多网页资料集合问答
- PDF 上传与解析
- PDF 阅读与问答
- 多文档 RAG

### 阶段 4：论文阅读与写作平台
- 独立 Web 平台
- PDF/Markdown 双视图阅读
- 标注、翻译、总结
- AI 辅助写作与改写
- 新旧内容 diff 对比
- 接受/拒绝修改

## 产品关系判断
- Chrome 插件是浏览器场景下的轻入口。
- 独立 Web 平台是重阅读、重写作、重编辑场景的主产品。
- 两者应共享同一套后端能力，包括用户、会话、文档、模型调用与检索能力。

## 当前核心判断
- 前期不把所有重能力塞进插件。
- 前期先把通用聊天和网页辅助体验做好。
- 后期的 PDF、知识库、论文平台能力应作为自然扩展，而不是前期一次性做满。
