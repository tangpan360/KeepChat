# V1 Scope

## V1 目标
先做一个真正可用、可安装、可持续迭代的 Chrome 侧边栏 AI 助手，优先验证基础聊天体验和普通用户高频场景。

## V1 核心功能
- 文本聊天
- 多轮对话
- 流式回复
- 图片上传或拖拽问答
- 历史会话
- 新建对话与切换对话
- 基础模型切换
- 基础快捷动作，如翻译、总结、解释、改写

## V1 建议保留但可简化的能力
- 基础登录状态
- 会话重命名与删除
- `options` 页面中的基础动作管理
- 前期 BYOK / 自定义 API 配置入口
- 本地草稿与最近会话恢复

## V1 后续优先能力
- 选中文本引用
- 右键发送到侧边栏
- 当前网页作为上下文加入会话
- 引用卡片展示
- 输入框自动聚焦，减少二次点击
- 当前网页问答入口

## 暂不放入 V1 的能力
- 多网页资料集合问答
- PDF 上传与解析
- 多文档 RAG
- 论文阅读器
- 论文编辑器
- diff 审核
- 复杂 agent 工作流

## 当前设计重点
- 先把聊天主链路做顺。
- UI 上优先保证轻量、直接和低打扰。
- 所有网页相关能力都通过显式用户操作进入会话。
- 不在首版就引入过重权限和复杂系统。

## V1 非目标
- 不把插件做成完整知识管理平台。
- 不把所有未来能力都预埋成复杂目录和服务。
- 不提前做重型微服务架构。

## 当前实现建议
- 产品上先验证“通用聊天 + 图片问答 + 历史会话 + 快捷动作”。
- 架构上按长期分层考虑，但实际实现保持轻量。
- 数据结构上为 `Attachment` 和 `ContextItem` 预留扩展空间，方便后续接网页、PDF 和 RAG。
