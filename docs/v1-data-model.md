# V1 Data Model

## 目的
本文件用于定义 KeepChat 在当前阶段的数据模型边界，帮助后续继续细化接口、状态管理、存储策略与 AI 上下文组织方式。

本文件关注：
- 当前版本有哪些核心对象
- 每个对象负责承载什么信息
- 哪些数据适合本地存储
- 哪些数据适合云端主存储
- 哪些字段是当前阶段必须的，哪些只是后续预留

本文件不展开数据库表结构、ORM 模型或具体 API 字段命名。

## 当前阶段数据建模原则
- 会话数据与 UI 临时状态分开
- 本地缓存与云端主存储分开
- 会话、消息、附件、引用上下文分开
- 会话中的“当前默认模型”与“消息真实生成模型”分开
- 当前阶段只建满足 V1 使用的核心模型，不提前设计过多未来字段
- 产品主数据模型与 LangChain / LangGraph 的运行时 state、memory、checkpointer 分开
- 当前以产品层数据为正式数据源，LangChain persistence 仅作为 AI 运行时辅助层按需使用

## 顶层核心对象
当前建议围绕以下对象组织数据：

1. `Conversation`
2. `Message`
3. `Attachment`
4. `ContextItem`
5. `QuickAction`
6. `ModelSelectionState`
7. `LocalDraftState`

---

## 一、Conversation

### 作用
表示一段对话会话，是历史列表和聊天主区的基础对象。

### 当前职责
- 承载会话级信息
- 为消息列表提供归属关系
- 为历史列表提供展示数据
- 保存当前默认模型状态

### 当前必须包含的信息
- 会话唯一标识
- 会话标题
- 创建时间
- 最近更新时间
- 当前默认模型名
- 消息总数

### 当前展示上需要用到的信息
- 标题
- 当前默认模型名
- 最近更新时间
- 消息总数

### 当前阶段不强求的内容
- AI 自动生成标题
- 会话标签
- 会话分组
- 项目空间归属

### 后续可预留方向
- 是否包含图片
- 是否包含网页上下文
- 是否包含 PDF 资料
- 是否置顶

---

## 二、Message

### 作用
表示会话中的一条消息，是聊天内容的最小核心单元。

### 当前职责
- 表示用户输入或模型回复
- 支撑聊天主区展示
- 作为 AI 上下文的一部分参与后续对话
- 支撑复制、编辑、删除、重新生成等能力

### 当前必须包含的信息
- 消息唯一标识
- 所属会话标识
- 消息角色
  - `user`
  - `assistant`
- 当前有效内容
- 创建时间

### 模型相关信息
对于模型回复消息，当前应额外保存：
- 真实生成模型名
- 是否由模型生成

说明：
- 用户消息显示 `You`
- 模型消息显示真实模型名
- 历史消息的模型名不因当前默认模型切换而改变

### 当前建议保留的状态信息
- 是否被编辑过
- 是否可重新生成

### 当前阶段产品含义
- 消息不是纯只读日志
- 当前保存后的内容会参与后续上下文

### 后续可预留方向
- 原始内容与当前内容的区分
- 重新生成版本记录
- 消息级操作历史

---

## 三、Attachment

### 作用
表示附加到消息中的文件对象，当前主要是图片。

### 当前职责
- 承载图片问答所需的图片数据
- 区分“文本消息”与“图文消息”
- 为模型能力校验提供依据

### 当前必须包含的信息
- 附件唯一标识
- 所属会话或待发送上下文归属
- 附件类型
  - 当前主要是 `image`
- 附件来源
  - 上传
  - 拖拽
- 当前状态
  - 待发送
  - 已发送

### 当前建议保留的信息
- 文件名称或展示名称
- 预览地址或本地引用

### 当前阶段规则
- 当前模型是否支持图片，主要由当前待发送附件决定
- 历史中已有图片，不代表当前这一轮不能切换到纯文本模型继续对话

### 后续可预留方向
- PDF
- 音频
- 网页截图
- 结构化附件类型

---

## 四、ContextItem

### 作用
表示“不是用户直接手输文本，但被作为上下文加入对话”的内容对象。

当前最典型的是：
- 引用托盘中的选中文本片段

后续可能扩展为：
- 当前网页上下文
- 网页片段
- PDF 片段
- 多网页资料片段

### 当前职责
- 承载引用托盘内容
- 与用户输入区分开
- 作为 AI 请求时的补充上下文

### 当前必须包含的信息
- 上下文对象唯一标识
- 所属会话或当前待发送上下文归属
- 上下文类型
  - 当前主要是 `quote`
- 文本内容
- 创建时间

### 当前建议保留的信息
- 来源说明
  - 例如来自网页选中文本
- 当前是否仍保留在引用托盘中

### 当前阶段规则
- 引用内容进入托盘后，不自动发送
- 用户补充问题后统一与输入一起发送

### 后续可预留方向
- 当前网页整体上下文
- 网页证据片段
- PDF chunk
- 多网页检索结果

---

## 五、QuickAction

### 作用
表示默认动作和用户自定义动作的配置对象。

### 当前职责
- 承载快捷动作名称与提示词
- 支撑网页选中文本后的快捷执行
- 支撑 `options` 页动作管理

### 当前必须包含的信息
- 动作唯一标识
- 动作名称
- 提示词内容
- 是否启用
- 排序位置
- 动作类型
  - 默认动作
  - 自定义动作

### 当前阶段规则
- 默认动作至少包含：`引用`、`解释`
- 自定义动作统一自动发送
- 自定义动作不进入引用托盘

### 当前不要求的信息
- 动作分类
- 图标
- 导入导出格式

### 后续可预留方向
- 分组
- 模板共享
- 场景化动作集合

---

## 六、ModelSelectionState

### 作用
表示“当前会话下一次发送默认使用什么模型”的状态对象。

### 当前职责
- 记录当前默认模型
- 支撑模型切换
- 为发送前能力校验提供基础

### 当前必须包含的信息
- 所属会话标识
- 当前默认模型名
- 当前模型是否支持图片

### 当前阶段规则
- 当前默认模型只决定“下一次发送”
- 历史消息中的模型名由消息对象单独记录

### 后续可预留方向
- 模型 provider
- 模型档位
- 模型说明信息

---

## 七、LocalDraftState

### 作用
表示本地临时状态，不属于正式会话历史，但直接影响交互体验。

### 当前职责
- 保存当前输入草稿
- 保存待发送引用托盘
- 保存待发送附件
- 保存 UI 临时状态

### 当前建议包含的信息
- 当前输入框文本
- 当前待发送引用列表
- 当前待发送附件列表
- 悬浮按钮总开关状态
- 最近打开的会话标识

### 当前阶段规则
- 本地草稿不等于正式会话历史
- 正式发送成功后，再写入会话与消息数据

---

## 八、本地与云端的边界

### 本地优先保存
适合放在插件本地状态中的内容：
- 当前输入草稿
- 当前待发送引用托盘
- 当前待发送附件状态
- 悬浮按钮总开关
- 最近打开会话

### 云端主存储
适合放在云端正式数据中的内容：
- 会话
- 消息
- 自定义动作
- 用户设置
- 附件元数据
- 后续网页 / PDF / 资料数据

### 当前原则
- 本地负责交互体验
- 云端负责正式数据与长期同步

---

## 九、当前最关键的数据关系

### Conversation 与 Message
- 一个会话包含多条消息
- 会话负责列表展示级信息
- 消息负责具体内容

### Message 与 Attachment
- 某条消息可带附件
- 当前主要是图片

### Message 与 ContextItem
- 某次发送可以同时带文本输入与引用内容
- 引用内容不是消息正文的一部分，而是独立上下文对象

### Conversation 与 ModelSelectionState
- 会话有一个当前默认模型状态
- 消息有自己真实生成时的模型名

### QuickAction 与 Options
- 动作配置由 `options` 页管理
- 配置结果作用于网页选中文本场景

---

## 十、当前阶段不纳入核心数据模型的内容
以下内容当前可以先不纳入 V1 的正式数据模型重点：
- 网页答案定位结果对象
- PDF 文档对象
- 多网页资料集合对象
- 多文档 RAG 检索结果对象
- diff 审核对象
- 复杂 agent 运行状态对象

这些能力后续进入当前版本时，再单独扩展模型即可。

## 当前使用建议
- 如果后续开始设计 API，应先围绕 `Conversation`、`Message`、`Attachment`、`ContextItem`、`QuickAction` 展开。
- 如果后续开始落地本地状态管理，应优先围绕 `LocalDraftState` 定义状态边界。
- 如果后续新增网页整体问答、PDF、RAG 等能力，应优先判断是扩展 `ContextItem` 还是新增独立对象。
